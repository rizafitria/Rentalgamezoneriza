# 🎮 RentalGameZone

## 📌 Deskripsi Proyek

**RentalGameZone** adalah aplikasi penyewaan PlayStation berbasis Java Console yang dibuat untuk membantu petugas rental dalam menghitung biaya sewa dan menampilkan rincian pembayaran pelanggan. Aplikasi ini dikembangkan menggunakan bahasa pemrograman Java melalui Apache NetBeans IDE untuk memenuhi latihan praktikum Pemrograman Java Dasar.

Aplikasi ini menyediakan dua pilihan konsol, yaitu PlayStation 4 (PS4) dan PlayStation 5 (PS5). Pengguna dapat memasukkan nama pelanggan, memilih konsol, menentukan durasi bermain, serta memilih tambahan minuman. Program akan menghitung biaya sewa, diskon, dan total pembayaran secara otomatis.

## ✨ Fitur Aplikasi

- Memasukkan nama pelanggan.
- Memilih konsol PlayStation 4 atau PlayStation 5.
- Menghitung biaya sewa berdasarkan durasi bermain.
- Memberikan diskon 10% untuk durasi bermain minimal 3 jam.
- Menambahkan minuman seharga Rp5.000 secara opsional.
- Menampilkan struk pembayaran secara otomatis.
- Melakukan transaksi baru tanpa menjalankan ulang program.

## 💰 Daftar Harga

| Jenis Layanan | Harga |
|---|---:|
| PlayStation 4 (PS4) | Rp8.000/jam |
| PlayStation 5 (PS5) | Rp12.000/jam |
| Tambahan Minuman | Rp5.000 |

**Ketentuan diskon:** Diskon sebesar 10% diberikan apabila pelanggan bermain selama minimal 3 jam. Diskon dihitung dari biaya sewa sebelum ditambahkan biaya minuman.

## 🛠️ Teknologi yang Digunakan

- Java
- Apache NetBeans IDE
- Java Console
- Scanner untuk input data

## ▶️ Cara Menjalankan Aplikasi

1. Buka proyek `RentalGameZone` di Apache NetBeans IDE.
2. Buka file Java yang berisi method `main()`.
3. Jalankan program menggunakan tombol **F6** atau menu **Run Project**.
4. Masukkan nama pelanggan.
5. Pilih jenis konsol yang akan disewa.
6. Masukkan durasi bermain dalam satuan jam.
7. Tentukan apakah ingin menambahkan minuman.
8. Periksa struk dan total pembayaran pada jendela Output.
9. Pilih apakah ingin melakukan transaksi baru atau mengakhiri program.
